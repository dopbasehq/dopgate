# Reference

- [REST API](/reference/api): every route, its authentication, and its status.
- [Errors](/reference/errors): the response shape and every error code.
- [Security model](/reference/security): how passwords, tokens, and secrets are stored.
- [Audit events](/reference/audit-events): what the audit log records and how to verify it.
- [Glossary](/reference/glossary): the terms these docs use.

The running server describes its own API at `/api/docs` (Swagger UI) and `/api/v1/openapi.json`. That description is generated from the code, so it is always current for the binary you run.
